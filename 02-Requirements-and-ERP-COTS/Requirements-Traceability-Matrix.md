# Requirements Traceability Matrix (RTM)

| Req ID | Business Objective | Requirement | Priority | Source / Owner | Fit-Gap | Solution / Deliverable | Test Case | UAT Result | Status |
|---|---|---|---|---|---|---|---|---|---|

## Fit-gap classifications
- **Standard:** Supported by standard ERP/COTS capability.
- **Configure:** Met through supported configuration.
- **Integrate:** Requires an interface or dependent system.
- **Process change:** Business process changes to adopt the solution.
- **Extension / customization:** Requires additional solution work and governance.
- **Further review:** Decision or analysis is still required.

## Traceability checks
- [ ] Every approved requirement has an accountable business owner.
- [ ] Every requirement maps to a solution decision or deliverable.
- [ ] Acceptance criteria are testable.
- [ ] Critical requirements map to test/UAT evidence.
- [ ] Changes are reflected in scope, schedule, risk and test planning.
