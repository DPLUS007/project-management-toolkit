## Due diligence
- [ ] References / implementation track record reviewed
- [ ] Key assumptions and exclusions documented
- [ ] Commercial dependencies identified
- [ ] Data ownership / portability considered
- [ ] Support and escalation model understood
- [ ] Contract/SOW deliverables align to project acceptance criteria

> Procurement, legal, security and architecture specialists should own their formal assessments where applicable.
