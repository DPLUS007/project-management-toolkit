# RACI Matrix

**R = Responsible · A = Accountable · C = Consulted · I = Informed**

| Deliverable / Activity | Sponsor | Project Manager | Business Owner | Technical Lead | Vendor | SMEs / Users |
|---|---|---|---|---|---|---|
| Project charter | I | R | C | C | I | I |
| Requirements approval | I | R | A | C | C | C |
| Solution / fit-gap decisions | I | R | A | C | C | C |
| Testing / UAT | I | R | A | C | C | R |
| Cutover readiness | C | R | A | R | R | C |
| Go / no-go decision | A | R | C | C | C | I |
| Handover / closure | I | R | A | R | C | I |

> Adapt roles and activities to the project's governance model. Avoid multiple Accountable owners for the same decision where possible.
