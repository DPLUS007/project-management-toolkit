# RAID Register

**RAID = Risks · Assumptions · Issues · Dependencies**

| ID | Type | Description | Impact | Likelihood | Severity / Priority | Owner | Response / Next Action | Due | Status | Escalation |
|---|---|---|---|---|---|---|---|---|---|---|

## Review practice
- Convert assumptions into validated facts or risks when appropriate.
- Escalate issues that exceed agreed tolerance.
- Link dependencies to milestones and accountable owners.
- Review high-impact items in status reporting and governance meetings.
- Close items only when the resolution or acceptance is documented.
